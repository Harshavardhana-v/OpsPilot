1. Backend — start server
cd C:\projects\opspilot\backend
npm run dev

2. Login again and get fresh JWT
$loginBody = @{
    email = "your-email"
    password = "your-password"
} | ConvertTo-Json

$login = Invoke-RestMethod `
  -Uri "http://localhost:5000/api/auth/login" `
  -Method POST `
  -ContentType "application/json" `
  -Body $loginBody

$token = $login.token
$headers = @{
    Authorization = "Bearer $token"
}

Check token:
$headers

3. Test incidents
$response = Invoke-RestMethod `
  -Uri "http://localhost:5000/api/incidents" `
  -Headers $headers `
  -Method GET

$response.incidents | Select-Object id,title,status

4. Browser console — check JWT
Press F12 → Console:
localStorage.getItem("token")

If it returns null, login through your web app again.
Then check:
console.log("Token:", localStorage.getItem("token"));

5. Check frontend API response
fetch("http://localhost:5000/api/incidents", {
  headers: {
    Authorization: `Bearer ${localStorage.getItem("token")}`
  }
})
.then(r => r.json())
.then(data => console.log("INCIDENTS:", data))
.catch(err => console.error(err));

If this console shows the 10 incidents, the backend + JWT are working and we only need to fix the frontend api.js configuration.
